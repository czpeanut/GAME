# 焦土台灣：焦土歸途 — Ch.1 灰盒原型（Godot 4.5）

2D 俯視（3/4 視角）戰術生存。這個資料夾是獨立的 Godot 專案，不影響 repo 根目錄原本的 JS 橫向捲軸遊戲（Hollow Runner）。

## 執行
- **直接玩**：Windows 版 `ScorchedEarth_Ch1.exe`（單一檔案，雙擊）。
- **開專案**：用 Godot **4.5.1**（標準版，非 .NET）開啟本資料夾的 `project.godot`，按 F5。

## 操作
| 動作 | 按鍵 |
| --- | --- |
| 移動／跑步（吵）／蹲姿（靜、視野小） | WASD／Shift／C 或 Ctrl |
| 瞄準方向／開槍 | 滑鼠／左鍵 |
| 按住瞄準（準星縮小、射程 +25%、光錐變窄變遠） | 右鍵 |
| 螺絲起子（從背後 = 無聲擊殺） | Q 或 V |
| 換彈匣／排障／卸下超裝子彈 | R |
| 硬塞彈匣到 20 發（卡彈率 60%） | T |
| 手電筒／互動（部分需長按） | F／E |
| 回標題 | Esc |

## 手感設定
- **ADS 準星**：右鍵按住約 1.1 秒由腰射收到定點精準（`gun.aim`）；移動、連射會讓準星膨脹，滿瞄時顯示 AIM LOCK。
- **移動方向與瞄準方向不同會減速**：夾角超過 25° 開始減速，正後方退行為 60%（`player.aim_penalty`）。
- **光線**：腰射寬光錐，瞄準時窄光錐、射程更遠；槍口閃光有動態光；光柱內有飄浮灰塵；防空洞有閃爍營火。

## 已實作（對照 GDD）
- **聲學共鳴圈**：踩碎玻璃 192 px、跑步 112 px、槍聲 480 px、蹲走 0；隔牆半徑減半。敵人用視錐＋聽覺，聽到聲音會去調查。
- **T65K2 卡彈**：標準 15 發；硬塞超過 15 發卡彈率 60%；鹽鏽 +12%；除鏽（針車油）後 2%。雙進彈排障損失 1 發、不退殼不損失。
- **蹲姿鑽鐵捲門**、**背刺**、**手電筒光錐＋牆壁遮光**、**暗區**、**屋頂淡出（X-Ray 的 2D 簡化版）**。
- **關卡**：防空洞 → 派出所（針車油）→ 服務處（M-01 文件）→ 超商（正門碎玻璃／側繞加油站撬後門）→ 救出李致晴（可長按 E 請她包紮）→ 東北撤離點。
- 結算畫面統計：槍數、卡彈、噪音事件、無聲擊殺，並給「幽靈／安靜獵人」評價。

## 調數值
所有數字在 `data/balance.json`。Windows 版可把這個檔案放在 exe 旁邊，**不用開 Godot** 就能覆蓋。

## 自動測試
```bash
godot --headless --path . --fixed-fps 60 res://test/test_runner.tscn
```
41 項：卡彈機率統計（2 萬次抽樣）、換彈／排障規則、各區可達性、鐵捲門蹲站差異、聲波半徑、敵人聽覺、背刺、槍戰、撬門捷徑、救援到過關。

## 素材
- **沿用 repo 既有**：`assets/reused/` — 瓦礫地面、街屋背景（標題畫面）、老伯立繪（墳墓對話）。
